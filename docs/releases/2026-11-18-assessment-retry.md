# إعادة محاولة التقييم — 18 نوفمبر 2026

من النتائج، افتح إجابة الطالب ثم اختر «إعادة المحاولة» وأكد العملية. تحذف الإجابة
السابقة ومرفقاتها ودرجتها واعتماد المهمة فورًا، وتتاح إجابة جديدة لنفس الطالب
في نفس القبلي أو البعدي أو المهمة، حتى بعد إغلاق الإتاحة العامة. تبقى الأسئلة
وقالب المستند وروابط المهمة وملفاتها الأصلية كما هي. يمكن تكرار الإجراء بعد
كل تسليم؛ لا يطلب سببًا ولا يضيف سجل محاولات أو منفذ الإجراء أو وقته.

الفرصة خاصة بالطالب والإدارة ونوع التقييم، وتستهلك مع نجاح التسليم فقط.
لا تمنح بقية الطلاب إتاحة، ولا تسمح بإجابتين معتمدتين. المشرف مقيد بفرعه؛
النتائج المؤرشفة محمية، واعتماد الاجتياز المقفل يجب إعادة فتحه أولًا.

يتضمن الإصدار جدول `assessment_retries` لحفظ الإتاحة الحالية فقط دون بيانات
تاريخية. وافق المستخدم على النشر؛ يؤخذ احتياطي لقاعدة البيانات والتخزين وملف
البيئة قبل الترحيل، وتراجع سلامة البيانات السابقة قبل تفعيل الإصدار.
