# عرض إجابات الاستبيان بالاسم

من لوحة التحكم ← استبيان الرضا ← اختر الدورة، يظهر قسم «إجابات الاستبيان»
أسفل المؤشرات. يمكن البحث بالاسم أو رقم الدخول وفتح «عرض الإجابات» لقراءة
التقييمات والإجابات النصية لكل مشارك. القائمة مقسّمة إلى صفحات من 20 مشاركًا.

تُربط الإجابات برقم الدخول، فلا تُدمج أسماء الأشخاص المتطابقة. يُعرض الاسم
الحالي عند توفر الحساب، وإلا يُستخدم الاسم المحفوظ وقت الإجابة. فتح التفاصيل
والبحث والتنقل بين الصفحات للقراءة فقط، ولا يغيّر الردود أو درجات التقييم.

تظهر الردود المحفوظة سابقًا للدورة دون ترحيل أو إعادة إرسال. يحافظ الخادم على
نص السؤال المحذوف إذا كان محفوظًا تاريخيًا، مع ربطه بالإدارة والدورة الصحيحتين.
تبقى الأسئلة المحذوفة خارج نموذج الاستبيان والمؤشرات الحالية.

تُستخدم صلاحية عرض استبيان الرضا الحالية. يبقى التعديل مرتبطًا بصلاحيته المستقلة،
ويحصر الخادم ردود المشرف بفرعه وردود المشارك بحسابه، ويمنع بيانات الإدارات الأخرى.

لا توجد تغييرات في مخطط قاعدة البيانات ولا أوامر SQL مطلوبة.

التحقق: اختبارات التجميع والبحث وأكثر من 1000 مشارك، واختبارات الخادم للردود
القديمة وحذف الأسئلة والترقيم وعزل الإدارة والفرع والهوية، وفحص الجوال والكمبيوتر
للأسماء المتطابقة والطويلة والتقييمات والنصوص وتبديل الدورات والصلاحيات وإعادة التحميل.
